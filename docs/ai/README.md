# Разработка с coding-агентами и LLM

Этот раздел даeт модели короткий и непротиворечивый контекст для разработки
программ на T-Invest Python SDK. Он предназначен как для coding-ассистентов,
так и для приложений, в которых LLM участвует в анализе или подготовке
торгового решения.

## С чего начать

1. [Карта SDK](sdk-map.md) — актуальные импорты, клиенты и сервисы.
2. [Реальный контур и песочница](real-vs-sandbox.md) — отличия режимов и
   выбор подходящего сценария.
3. [Безопасность торговых программ](trading-safety.md) — границы между
   стратегией, риск-контролем и исполнением.
4. [Типичные ошибки](common-pitfalls.md) — request-модели, лоты, цены,
   даты, идентификаторы и повторные запросы.
5. [Skill и промт для разработки](prompts/build-trading-program.md) и
   [skill и промт для ревью](prompts/review-trading-program.md).

## Источники истины

`AGENTS.md` задаeт правила работы с репозиторием и требования безопасности.
Для фактов об API при расхождении информации используйте следующий приоритет:

1. текущие Python-сигнатуры и proto-файлы;
2. тесты текущей версии;
3. `BREAKING_CHANGES.md`;
4. документация и примеры текущего репозитория;
5. внешние материалы.

LLM не должна восстанавливать имя метода или поле запроса по памяти. Если
определение не найдено в текущем репозитории, это нужно назвать неизвестным,
а не заменять предположением.

## Канонические файлы

- `AGENTS.md` — канонические правила изменения самого репозитория;
- `.agents/skills/t-invest-python-sdk-bot-builder/SKILL.md` — полный workflow разработки
  и ревью торговых программ для агентов с поддержкой skills;
- `docs/ai/prompts/` — самодостаточные fallback-промты для агентов без
  поддержки skills;
- этот раздел — прикладной контекст для генерации торговых программ;
- `examples/` — примеры использования, но их импорты и сигнатуры следует
  сверять с актуальным gRPC-кодом.

Файлы под конкретные ассистенты должны ссылаться на `AGENTS.md` как на
канонический источник общих правил. Skill намеренно самодостаточен в
предметном workflow: каждое требование fallback-промтов для разработки и
ревью должно также присутствовать в skill. При изменении торгового требования
синхронизируйте `AGENTS.md`, относящуюся страницу этого раздела, skill и
соответствующий fallback-промт.
